## 已移除的故障来源

- 主题以 `html` 的原生状态为准，清除旧版 `body.dark/light` 残留。宿主主题使用语义标记和统一正文色，避免亮色页面继承反色正文。
- 壁纸使用独立绘制层。IndexedDB 写入以事务完成为准；异步读取和上传带版本号，关闭壁纸、删除、更换图片、销毁应用都会使旧结果失效。读取失败保留资产引用。
- 大纲空态也保留工具栏和订阅。一个管理器负责内容更新，忽略自身 DOM 变化；文本未变时更新节点引用，不重建目录。标题层级按回答隔离，ID 包含路由与消息身份。
- 滚动、返回锚点和大纲跳转使用 `ScrollManager`。移除重复强制滚动、伪造输入与修改原生滚动属性的逻辑；真实用户输入中止平滑滚动，自动滚动保护让出导航控制权。
- SPA 导航只有一个宿主刷新调度入口。路由变化清理旧锚点、取消旧滚动并重新绑定阅读记录。切离大纲停止其监听。
- 初始化等待明确就绪事件，取消多层固定延迟和重复创建重试。资源释放后，迟到的壁纸读取不能重新创建 URL 或观察器。

## 交互约定

保留现有安静、高密度的侧栏设计和品牌图标，不引入新视觉组件或生产依赖。标签页支持方向键、Home、End 和正确的焦点状态；窄窗口以覆盖式面板显示，不挤压正文。主题与关于弹窗同步关闭、返回触发按钮焦点，快速重开不会出现重复节点。提示消息使用 `role="status"`。

## 新版 ChatGPT 现场适配（版本仍为 2.6.0）

2026-10-21 在已登录的实际会话中复现了旧测试未覆盖的三个问题，并据此补充适配：

- 新页面没有 `data-message-author-role`、`conversation-turn-*` 或 `article`。使用 `data-content-search-unit-key` / `data-chatgpt-search-unit-key` 区分用户和助手，以 `data-chatgpt-selection-message-id` 和 `data-turn-key` 保持消息身份。正文在 `data-markdown-text-style="assistant-message"` 中；屏幕阅读器专用的 `h4.sr-only` 不纳入大纲。
- DIL 正文渲染器拥有独立的 `data-theme` 调色板。仅切换 html 会留下浅色背景上的深色模式文字。现在同步包含 `data-dil-message-id` / `data-oai-writing-block-surface` 的原生主题作用域，并处理延迟插入与原生重新渲染。
- 会话祖先用 `::before` 绘制不透明背景，元素自身的 computed background 却透明。壁纸开启时清除已识别结构路径的伪元素背景，关闭时恢复原样；不清除正文卡片内部结构。

真实输入区使用 `data-composer-markdown`，可能没有 ID，页面内另有可编辑写作卡片。输入框识别优先使用该语义标记并排除写作卡片，避免提示词插入错误区域。

现场已核验三个提问和三个回复摘要、大纲搜索与跳转、亮暗切换、原有壁纸开关与刷新恢复。刷新过程中曾出现原生“无法加载此回复”：关闭 Helper 后刷新仍能复现，重新进入原会话及独立标签页后回复完整恢复；没有把该失败状态算作大纲验收通过。回归套件新增五个 modern 场景，总计 21 项；fixture 仅保存合成内容和结构，不包含用户会话或壁纸。

## 壁纸与输入区显示约定

- 壁纸只应用用户设置的模糊值，不再叠加固定白色／黑色遮罩；模糊为 0 时也不额外扩大图片层。主题预览采用相同规则，不额外压暗、降低饱和度或增加 1px 模糊。
- 新版输入区的整宽背景是 `pointer-events:none` 的兄弟元素，无法通过鼠标命中栈发现。仅在输入区祖先路径上标记匹配的原生背景兄弟；壁纸开启时清空，关闭时恢复。
- 输入框玻璃层挂到 `data-composer-surface-variant` 的圆角外壳，继承原生圆角，不挂到方形的 `data-composer-body` 内层。保留输入、按钮、附件和弹出菜单的结构。
- 回归增加明暗两种模式下的底部横条、圆角外壳、关闭壁纸恢复原生背景、模糊 0 及预览无额外滤镜检查，总计 23 项。

## 毛玻璃与面板交互

- 消息强度 0–100 对应 0–32px 模糊；侧栏／右栏强度对应 0–40px，同时调整玻璃底色透明度。原始与彩色主题使用同一映射，0 不再偷偷保留最低模糊。
- 左右栏共用玻璃底色与模糊值；右栏只保留一层毛玻璃，内部控件不重复模糊。输入区跟随侧栏强度，不再随消息强度联动。消息毛玻璃启用时，写作卡片透出父级玻璃材质。
- 文字增强为左右栏提供同一明暗衬底，强度 0–100 对应 0–0.65 的衬底 alpha；左右栏即时同步，预览使用同一映射。关闭壁纸时相关控件禁用但保留值；消息和增强开关分别控制对应强度的可用性。
- 面板计算宽度小于 164px 时结束拖拽并收起；重新展开恢复拖拽前宽度。普通拖动仍保存最终尺寸，失焦或销毁时释放监听。
- 快速菜单和快捷键设置只保留标题与控件。回归覆盖以上行为及保存恢复，总计 30 项。

## 缓存会话切换

新版 ChatGPT 会保留多个主区，通过 `data-app-shell-active-page` 和祖先显示状态切换。不能使用第一个 `main` 作为当前对话：它可能是 DOM 中更早的隐藏缓存。

- `ChatGPTAdapter.getChatContainer()` 优先选择显式激活的主区，无激活标记时选择实际可见主区；背景、消息、输入框、滚动容器统一使用该边界。
- 输入框查找每次清理旧引用，同一选择器下跳过隐藏节点；缓存滚动容器必须仍属于活动主区。
- 主题监听覆盖主区激活、显示状态和结构变化。只改属性、不重建节点的切换也会重新标记；消息尚未载入的空线程壳也会透出壁纸。
- 主区身份变化时重新绑定页面功能；仅实际路径变化时重置阅读锚点和触发会话同步。壁纸资源不因切换重读或新建，过期页面标记按差异移除。
- 已在真实页面连续切换三个会话并执行两次后退、两次前进，确认无需刷新。新增缓存 A/B、属性切换、历史导航、延迟载入、资源及刷新稳定性回归，总计 35 项。

## 公式双击复制

`58-formula-source.js` 统一处理公式根节点、源码和定界符，`60-copy-manager.js` 负责双击及剪贴板反馈。点击 KaTeX 字符、上下标或分数线时，先定位完整 `.katex`，再读取与 HTML 排版层同级的 MathML `annotation[encoding="application/x-tex"]`。明确的 `data-latex`、`data-math`、`data-formula` 可作为备用来源。

- 不使用 `.mathnormal` / `.katex-html` 的拼接文本、朗读用的 `aria-label` 或整段回复文字猜测 LaTeX；没有可靠源码时提示未复制，保留原剪贴板。
- 独立公式根据 `.katex-display`、DIL `data-d-block` 或 MathML `display="block"` 判断；高的行内分数仍是行内公式。只去掉成对外层定界符，保留反斜杠、括号、下标及多行结构。
- 代码块和可编辑区域保留原交互。此模块处理双击公式；整段回复复制及导出使用各自的原有路径。
- 回归使用真实 KaTeX 生成 HTML+MathML，包括卡特兰数 `C_n=\frac{1}{n+1}\binom{2n}{n}=\frac{(2n)!}{n!(n+1)!}` 及 `C_4=\frac{8!}{4!\times5!}=14`，对复制字节和重新渲染分别验证。
- 新增八组双击回归，总计 51 项。卡特兰总式还在登录页面双击后由实际粘贴结果确认，完整保留 `\boxed`、分数、组合数和下标。浏览器自动化的隔离剪贴板不能直接读取网页写入的系统剪贴板，不能以空的工具读数判定真实复制失败。

### 图片输出边界

只导出预览中选中的已加载消息，按对话顺序排列。远程图片必须允许浏览器读取，无法读取时原位置显示说明，预览同时报告数量。预览最多显示前 4000 CSS 像素；保存包含全部选中内容。分页逐页渲染，单页通常不超过 2400 CSS 像素；单张长图超过 Canvas 像素预算时提示改用分页或降低清晰度。

图片、字体和文字在本地浏览器中处理；不上传到图片生成服务。导出文件中的原许可保留在随包发布的第三方说明中。

## 2.7.1：服务与作业边界重构

2026-10-22 在已登录页面复现：四个导出动作及批量列表共同报错 `adapter.fetchBackendResponse is not a function`。浏览器中缓存的主内容脚本与后来注入的导出脚本不属于同一构建；导出模块直接调用另一个入口中的内部对象方法，使版本差异变成运行时错误。原先用同一页面作用域注入全部脚本的 fixture 无法复现这个安装状态。

### 底层所有权

| 模块 | 唯一职责 | 不再负责 |
| --- | --- | --- |
| `shared/chatgpt-client.js` | 会话认证、工作区标识、401 续期、请求与响应体超时、取消 | DOM、UI、下载 |
| `shared/conversation-context.js` | 从明确路由解析当前会话 ID | 最近会话回退 |
| `helper/80-chatgpt-adapter.js` | 宿主 DOM 识别与会话列表适配 | 认证缓存和请求重试实现 |
| `exporter/repository.ts` | 后端形状转换、项目游标与实际分页偏移、附件并发上限 | 格式排版和界面状态 |
| `exporter/model/` | 数据类型、当前分支、不可变消息归并与思考内容归属 | 网络、存储和下载 |
| `exporter/exporter/` | 根据明确数据和设置生成文字、Markdown、HTML、图片 | 查询当前页面、获取全局宿主、请求会话 |
| `exporter/session.ts` | 捕获上下文与设置、管理作业、检查提交边界、生成唯一文件名、下载或复制 | 页面选择器 |
| `ui/SessionContext.tsx` | 为一个挂载实例传递服务 | 模块级可变宿主单例 |

`host.ts` 仅保留版本化合同，向导出提供 `request` 等明确能力，不传递 `adapter` 对象。`getExportHost` / `getExportPortal` 全局状态与混杂的 `api.ts` 已移除；Portal、请求、状态和下载属于一个 `ExportSession`。切换路由或销毁实例会取消作业，文件提交前再次核对当前上下文。

`legacy-host.ts` 是受限的 2.7.0 页面迁移边界：只接受已知公开回调与准确的旧安装版本，转换为当前协议，并使用独立的同源网络客户端；没有探测内部方法名或轮流尝试多个网络入口。新页面完全使用新合同。该边界让尚未关闭的旧页面恢复导出，同时不会把旧接口条件传播进格式转换和 UI。

### 构建一致性

主脚本、导出脚本、后台入口统一生成构建指纹。后台源码位于 `src/background/index.js`，由构建产生 `background/sw.js`。主脚本请求注入时携带指纹；后台与导出挂载边界均拒绝不匹配的构建，并显示可识别的更新错误。

三个入口先在独立临时目录编译，全部成功后逐文件原子替换正式脚本；编译失败保留上一次完整产物。临时目录在 `finally` 中校验路径并清理。

### 对抗性审查中的实际修复

- 认证请求并发合并；取消能够中断等待认证的调用方；超时覆盖响应体读取，避免只收到 HTTP 头后无限挂起。
- 工作区 cookie 使用分隔解析；工作区切换或查找失败明确中止，禁止静默改用个人账户导出。
- 当前格式转换只使用操作开始时捕获的设置；关闭、切页、取消限流等待后不再触发下载。
- 数据转换不修改原始 mapping；父链循环明确失败；缺少旧版 `recipient` 字段的消息不会整条消失；空续写片段不会拼出 `undefined`。父链遍历和思考归属查找改为线性处理。
- 批量分页支持服务器缩小页容量；偏移依据原始返回数量推进，重复页不继续循环。JSON ZIP 继续使用单会话对象文件，当前官方 JSON 继续使用数组。
- 长文件名保留扩展名；ZIP 文件名统一去重；异常标题不会使导入列表崩溃；HTML 原始代码转义，脚本 URL 与事件属性被净化。
- 会话管理器移除缓存轮询与重复调试读取，使用 `RuntimeScope` 管理延迟任务；销毁时取消同步，迟到结果不得写回存储。启动入口等待应用实际就绪，失败时释放实例。
- 图片选择有独立勾选标记、背景、文字状态与键盘焦点。无用引导段落已删除；状态、错误和必要的缺失图片提示保留。
